# Промпт генерации батча

Парный артефакт к формату импорта (`gas/Config.gs`, `IMPORT_COLUMNS`). Меняются колонки —
меняется и этот файл, одним коммитом. Иначе генератор начнёт отдавать то, что импорт
отклонит, и разбираться придётся построчно в листе `rejects`.

## Как пользоваться

1. Скопировать блок ниже в чат с моделью.
2. Заменить `{{СЛОЙ}}` и `{{ТЕМА}}`, при необходимости `{{КОЛИЧЕСТВО}}`.
3. Ответ вставить в лист `inbox`, начиная со второй строки.
4. Меню таблицы → `Eng_bot` → «Импортировать батч из inbox».

## Промпт

```
Ты готовишь батч лексики для персонального тренажёра английского.
Ученик: русскоязычный, уровень A2 в продукции и B1 в чтении технических текстов.
Работает продуктовым маркетологом в кикшеринге и бизнес-аналитиком в гостиничном ПО.
Цель — говорить с международными коллегами и читать спецификации.

Отдай ровно {{КОЛИЧЕСТВО}} строк в формате TSV (разделитель — символ табуляции),
без заголовка, без нумерации, без markdown-обёртки, без пояснений до и после.

Восемь колонок строго в этом порядке:
type <TAB> en <TAB> ru <TAB> example_en <TAB> example_ru <TAB> layer <TAB> topic <TAB> note

Правила:
- type: одно из word | collocation | phrase.
  Не меньше 70% строк должны быть collocation или phrase, а не word.
  Изолированные слова допустимы только там, где у слова нет типичного окружения.
- en: целевая единица, до 80 символов, в базовой форме. Без артикля, если он не часть единицы.
- ru: короткое значение, а не словарная статья. Без вариантов через слэш.
- example_en: одно естественное предложение, в котором единица употреблена буквально
  в том виде, как она записана в колонке en. Не переписывай единицу другими словами.
- example_ru: перевод примера, естественный по-русски, а не подстрочник.
- layer: одно из core | business | mobility | hospitality | tech. Для этого батча: {{СЛОЙ}}
- topic: одно слово или короткая метка по-английски, например release, metrics, pms.
- note: оставь пустым, если нечего добавить.

Запрещено:
- запятые вместо табуляций в качестве разделителя колонок;
- кавычки вокруг значений;
- переводы строк внутри поля;
- одна и та же единица дважды в батче;
- слова, которые ученик почти наверняка уже знает (уровень A1: make, take, good, work).

Тема батча: {{ТЕМА}}
```

## Проверка перед вставкой

Быстрый глазной проход, который экономит разбор `rejects`:

- строк ровно столько, сколько просил;
- в каждой строке семь табуляций;
- нет ни одной пары кавычек;
- в `example_en` целевая единица видна дословно;
- `layer` одинаковый во всех строках и совпадает с тем, что просил.

Импорт всё равно проверит это сам и отклонит с причиной. Но исправить в чате дешевле,
чем в таблице.

## Что делать с пиявками

Карточки, набравшие порог промахов, уходят в состояние `leech` и выпадают из очереди.
Их не лечит время — их лечит переформулировка. Раз в неделю:

1. В листе `cards` отфильтровать `state = leech`.
2. Скопировать колонки `en` и `ru`.
3. Отдать модели:

```
Вот единицы, которые я стабильно забываю. Для каждой предложи замену:
ту же идею, но как коллокацию или короткую фразу с конкретным контекстом,
а не изолированное слово. Если единица многозначна — раздели на две отдельные,
по одному значению каждая: интерференция между значениями и есть причина забывания.
Формат ответа — тот же TSV из восьми колонок.
```

4. Новый батч импортировать как обычно. Старые строки не удалять: они остаются
   как история, а `leech` уже исключён из очереди.
