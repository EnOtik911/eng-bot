# SESSION_LOG — журнал решений (человекочитаемый)

> Write-only для агентов (RULE 5): агенты дописывают записи, но НИКОГДА не читают файл
> целиком, чтобы «вспомнить, как решали раньше» — это стоит весь лог в токенах.
> Если прошлая запись действительно нужна — колонка `verify-ref` в CHANGELOG.md
> указывает точный диапазон строк, читать через `sed -n '<start>,<end>p'`.
> Язык записей: русский (RULE 6, исключение — этот файл адресован пользователю).
> Ротация: раз в квартал в `.context/archive/SESSION_LOG-YYYY-Qn.md`.
